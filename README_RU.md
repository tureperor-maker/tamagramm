# Talagramm — Android test wrapper

Это исходный Android-проект, который открывает локальный демо-интерфейс Talagramm внутри Android WebView. Он нужен для тестирования вида приложения на телефоне.

## Важно
- Это **не готовый APK**. Здесь исходники и автоматическая сборка APK через GitHub Actions.
- Демо локальное: онлайн-чат между разными телефонами и реальная регистрация через сервер не работают.
- Перед публичным распространением нужно заменить демо на подключённый и проверенный backend, добавить политику конфиденциальности и протестировать безопасность.

## Как получить APK через GitHub с телефона
1. Создай новый пустой репозиторий на GitHub.
2. Загрузи все файлы и папки из этого архива в репозиторий, сохранив структуру.
3. Открой вкладку **Actions** и запусти workflow **Build Talagramm test APK** (или сделай push в ветку `main`).
4. Когда сборка завершится, открой её и скачай artifact `Talagramm-Test-APK`.
5. Распакуй скачанный artifact и установи `app-debug.apk`. Android может попросить разрешить установку из этого источника.

Если у тебя нет GitHub, этот проект можно открыть в Android Studio на компьютере и собрать задачей `assembleDebug`.
